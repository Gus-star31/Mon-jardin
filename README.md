# Atelier des massifs

Outil pour composer les massifs et les haies du jardin selon l'exposition, le sol, le climat, l'arrosage et la place disponible : plan de plantation, vue de face selon l'âge du jardin, photos, calendrier de floraison et budget estimé.

- `index.html` : toute l'application (HTML, CSS et JavaScript dans un seul fichier, sans étape de build).
- `photos/` : photos libres de droits issues de Wikimedia Commons. Chaque fiche renvoie vers la page source de sa photo (auteur et licence).

Déploiement : Vercel publie automatiquement chaque modification poussée sur `main`.

Les données sur les plantes (rusticité, besoins en eau, croissance, prix) sont des ordres de grandeur indicatifs.
